# Expense Tracker
About the Project
This is a simple Python-based Expense Tracker project developed using OOP concepts.

The main purpose of this project is to help users manage their daily expenses and keep track of their spending.
Features
- Add daily expenses.
- Store expense details in JSON files.
- Maintain separate records for each user.
- View previous expense records.
- Sort expenses date-wise.
- Calculate total expenses.
- Display monthly expense summaries.
- Automatically save data without deleting previous records.
  
Technologies Used
- Python
- OOP Concepts
- JSON
- Datetime Module
